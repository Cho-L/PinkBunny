🐰 Pink Bunny 쉬운 설치 안내 (Windows 10/11)
========================================
이 프로그램은 크롬 유튜브 영상 제목을 OBS 화면에 보여줍니다.
비용: 무료 / 회원가입 없음 / Node.js 설치 없음

[1컴 사용자는]
① PinkBunny.exe 를 더블클릭하여 실행합니다. 검은 창은 닫지 마세요.
② 검은 창의 "Connection code:" 옆 8자리 코드를 메모합니다.
③ Chrome 주소창에 chrome://extensions 입력 → 오른쪽 위 개발자 모드 켜기.
④ "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 폴더 안의 extension 폴더 선택.
⑤ Chrome 오른쪽 위 퍼즐(확장 프로그램) → Pink Bunny → 서버 주소에 127.0.0.1 입력.
⑥ ②의 연결 코드 입력 → 저장 및 연결 확인.
⑦ OBS → 소스 + → 브라우저 → URL: http://127.0.0.1:38765 → 너비 420, 높이 130.
⑧ 크롬 유튜브 탭 새로고침 후 노래 재생!

[2컴 사용자는]
① 위 프로그램(PinkBunny.exe)과 OBS는 "송출 PC"에 설치/실행합니다.
② 확장 프로그램(extension 폴더)은 유튜브를 재생하는 "음악 PC"의 Chrome에 설치합니다.
③ 송출 PC의 검은 창에 표시된 "Streaming PC IPv4:" 주소(예: 192.168.0.10)와 8자리 코드를
   음악 PC의 Chrome 확장 프로그램에 입력합니다.
④ OBS의 브라우저 소스 URL은 송출 PC에서 http://127.0.0.1:38765 로 설정합니다.
※ 두 PC는 같은 공유기/사설 네트워크에 연결되어야 합니다.
※ Windows 방화벽이 뜨면 신뢰할 수 있는 개인 네트워크에서만 허용합니다.
※ 공유기 포트포워딩은 하지 마세요.

[문제가 발생하면]
- 확장 프로그램 오류: ZIP 파일을 직접 선택하지 말고 압축을 푼 extension 폴더를 선택하세요.
- 제목이 표시되지 않음: 유튜브 탭 새로고침, EXE 실행 여부, 연결 코드, IP를 확인하세요.
- OBS 화면이 안 보임: 브라우저 소스 URL과 너비/높이를 확인하세요.
- 검은 창을 닫으면 프로그램이 종료됩니다.
- Windows 보안 경고: 서명되지 않은 개인 배포 EXE에 경고가 뜰 수 있습니다.
  출처가 불분명한 파일은 실행하지 마세요.

* 이 프로그램은 영상에 표시된 제목/채널 정보를 가져오며 실제 음원을 인식하지 않습니다.
* 초기 베타 버전이므로 PC 환경에 따라 동작하지 않을 수 있습니다.
