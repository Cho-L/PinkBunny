🐰 Pink Bunny 그림으로 따라하는 쉬운 설치 (Windows 10/11)
======================================================

★ 그림 안내가 설치 프로그램에 같이 들어 있습니다!
  설치 뒤 시작 메뉴 → "Pink Bunny 그림 설치 가이드"
  또는 설치 폴더 안의 guide\index.html 을 더블클릭하세요.
  압축형 ZIP을 사용한다면 PinkBunny\guide\index.html 을 여세요.

먼저 딱 하나만 선택하세요: "유튜브 음악을 어느 PC에서 재생하나요?"

[A] 송출 PC에서 음악을 재생합니다 (가장 간단한 방식)
※ 방송 자체가 2컴이어도 음악을 송출 PC에서 틀면 A 방식입니다.

1) 송출 PC에서 PinkBunny.exe 실행. 설치 도우미가 브라우저에 열립니다.
2) Chrome 주소창에서 chrome://extensions 입력 → 개발자 모드 켜기
   → "압축해제된 확장 프로그램을 로드합니다" → 설치 폴더의 extension 선택.
   설치 도우미의 "확장 프로그램 폴더 열기" 버튼으로 폴더를 찾을 수 있습니다.
3) Chrome의 Pink Bunny 아이콘 → "연결 설정 · 문제 해결"
   → "1컴 자동 연결" 선택.
4) 송출 PC의 OBS → 소스 + → 브라우저 → 아래 주소 입력.
   URL: http://127.0.0.1:38765
   너비: 420 / 높이: 130
5) YouTube / YouTube Music 페이지 새로고침 후 음악을 재생해 보세요.

[B] 다른 PC에서 음악을 재생합니다 (2컴 연결)

1) 송출 PC에서 PinkBunny.exe 실행 및 OBS 브라우저 소스 설정.
   OBS URL은 송출 PC에서 언제나 http://127.0.0.1:38765 입니다.
2) 송출 PC의 extension 폴더를 음악 PC로 복사합니다.
   음악 PC Chrome의 chrome://extensions 에서 복사한 폴더를 등록합니다.
3) 송출 PC 설치 도우미에서 "다른 PC에서 재생"을 선택하고
   적합한 송출 PC의 사설 IP를 고른 뒤 "연결 주소 복사".
4) 연결 주소를 음악 PC로 안전하게 전달합니다.
   음악 PC의 Pink Bunny 확장 프로그램에서 "연결 설정 · 문제 해결"을 열고
   복사한 링크를 붙여넣은 다음 "2컴 연결 주소 적용" 클릭.
5) 음악 PC에서 유튜브 탭을 새로고침하고 재생합니다.
   송출 PC의 OBS에서 제목과 진행바가 나타나는지 확인해 주세요.

[주의]
- Pink Bunny는 영상 제목·재생 정보 위젯입니다. 음악 소리 전송 기능은 아닙니다.
  방송 오디오는 OBS에서 별도로 설정해 주세요.
- 2컴은 같은 신뢰할 수 있는 사설망에서 사용해야 합니다.
- 공유기에서 포트포워딩을 하지 마세요.
- 연결 주소에는 인증 코드가 들어 있으므로 공개 채팅·게시글에 공유하지 마세요.
- Windows 방화벽에서는 신뢰할 수 있는 개인 네트워크만 허용하세요.
- 설치된 EXE는 서명되지 않았으므로 Windows 보안 경고가 나올 수 있습니다.
  출처 확인 없이 경고를 무시하지 마세요.

[문제가 생기면]
- 설치 도우미가 안 뜸: 송출 PC에서 http://127.0.0.1:38765/setup 열기
- 그림 안내 다시 보기: 시작 메뉴의 "Pink Bunny 그림 설치 가이드"
- 확장 프로그램을 못 찾음: ZIP이 아니라 압축을 푼 extension 폴더를 선택
- 제목이 안 나옴: Chrome 확장 연결 확인 → 유튜브 탭 새로고침 → OBS 주소 확인
- 팝업 드롭다운이 닫힘: 확장 프로그램의 "큰 화면에서 설정" 버튼 사용
- 종료 방법: Windows 작업 표시줄 알림 영역의 Pink Bunny 아이콘 우클릭 → 종료
- 음성이 나오지 않음: OBS 오디오 장치/오디오 캡처 설정을 따로 확인

※ 그림은 순서를 돕는 예시 화면입니다. Chrome/OBS 버전에 따라 버튼 위치가 다를 수 있습니다.
※ 실제 음원을 분석하지 않고 유튜브에 표시된 영상 제목·채널 정보를 이용합니다.
