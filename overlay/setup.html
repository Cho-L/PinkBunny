🐰 Pink Bunny 설치 도우미

설치 안내가 자동으로 열렸어요! 아래 순서대로 진행해 주세요. 이 창은 송출 PC에서만 열어야 합니다.

① OBS 연결

OBS → 소스 추가 → 브라우저 → URL에 아래 주소 붙여넣기 · 크기 420 × 130

http://127.0.0.1:38765
② 크롬 확장 프로그램 설치

음악을 재생하는 PC의 크롬 주소창에 아래 주소를 입력한 다음 개발자 모드를 켜고, 압축을 푼 extension 폴더를 로드하세요.

chrome://extensions

폴더 열기 버튼을 누른 다음 크롬의 압축해제된 확장 프로그램을 로드합니다에서 열린 extension 폴더를 선택하면 돼요. 2컴은 음악 PC에도 이 폴더를 복사해야 해요.

③ 컴퓨터 선택 및 연결

다음 중 사용하는 환경을 선택해 주세요.

크롬에서 Pink Bunny 확장 프로그램을 열고 자동 연결 버튼을 누르세요. 코드 입력은 필요하지 않습니다.

송출 PC의 IP를 선택한 뒤 아래 연결 주소 복사 버튼을 누르세요. 복사한 링크를 메신저 등으로 음악 PC로 전달한 뒤, 음악 PC의 크롬 확장 프로그램 설정에 붙여넣으면 끝이에요.

연결 주소에는 개인 연결 코드가 포함됩니다. 공개 게시글이나 불특정 다수에게 공유하지 마세요. 두 PC는 같은 사설 네트워크를 사용해야 합니다.
④ 유튜브 음악 재생

음악 PC에서 유튜브 페이지를 새로고침하고 영상을 재생하세요. 송출 PC의 OBS에 제목이 표시됩니다.

연결 정보를 확인하는 중…

⚠ Pink Bunny 종료는 Windows 트레이 메뉴에서 할 수 있어요. Windows 방화벽에서 허용을 묻는 경우 신뢰할 수 있는 개인 네트워크만 허용하세요. 포트포워딩은 필요하지 않습니다.
